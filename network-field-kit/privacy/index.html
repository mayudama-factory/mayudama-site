Network Field Kit プライバシーポリシー

制定日：2026年11月7日 ／ 最終更新日：2026年11月7日 ／ 提供者：Mayudama Factory ／ English

Mayudama Factory（以下「当方」）は、iOS・iPadOS 向けのネットワーク診断アプリ「Network Field Kit」（以下「本アプリ」）における利用者の情報の取り扱いについて、以下のとおり定めます。

1. 当方が受け取る情報

本アプリには当方が運営するサーバーがなく、当方が利用者の情報を受け取ることも、利用者の情報にアクセスすることもありません。診断の結果、履歴、ブックマーク、テストプラン、設定は端末の中に保存されます。Pro で同期を有効にした場合に限り、履歴、ブックマーク、レポートの下書き、テストプラン、LAN 機器に付けた名前は利用者本人の iCloud にも保存されます（設定は同期しません）。通信は、次の 2 のとおり、端末から利用者が指定した宛先または第三者のサービスへ直接行われます。

2. 通信先と送られる情報

本アプリは診断のために通信を行います。どの通信でも、通信先には、インターネット通信の性質上、端末の IP アドレスが届きます。各通信先での情報の取り扱いは、各事業者のポリシーに従います。

通信先機能送られる情報・いつ
利用者が指定した宛先Ping、Traceroute、DNS、TLS、HTTP など入力したホスト名や IP アドレスへの通常の通信。利用者が「実行」したとき。LAN 内の機器（SNMP など）を指定した場合は、その機器へ通信します。
IPinfo、ipifyグローバル IP アドレスとその情報（ASN、国など）の取得、Traceroute／MTR の経路上の ASN の表示、Ping・TCP Ping の宛先の AS・国の表示（IPinfo）グローバル IP アドレスの取得では通信のみ（IP アドレスを調べるため）。Traceroute／MTR では、経路上のグローバル IP アドレス（ルーターや宛先のアドレス）を IPinfo に送り、ASN を調べます。Ping・TCP Ping では、宛先が公開（グローバル）IP アドレスのとき、その宛先の IP アドレスを IPinfo に送り、AS 番号・AS 名・国を調べます（私設・CGNAT・ループバック・リンクローカルの宛先は送りません。同じ IP アドレスは、結果を端末の中に 15 分間覚えて、送り直しません）。テストプランの手順として実行した場合も同じです。該当の画面を開いたとき、更新したとき、または Traceroute／MTR・Ping・TCP Ping を実行したとき。
Cloudflare（speed.cloudflare.com ほか）速度測定、通信の遅延の測定、ウォークテストの定期的な測定、DoH／DoT の確認測定用の通信（ダウンロード・アップロードの試験データ）、または入力したドメイン名の DNS 問い合わせ。端末の IP アドレスが Cloudflare に届きます。利用者が測定または「実行」したとき（速度測定の初回は同意の画面で確認します）。
利用者が指定した iperf3 サーバーiperf3 による速度測定測定用の TCP／UDP 通信のみ。利用者が入力したサーバーにだけ接続し、公開サーバーへ自動では接続しません。サーバーの管理者は端末の IP アドレスを知り得ます。利用者が「開始」したとき。
利用者が指定した宛先（Path MTU）Path MTU の探索入力したホスト名または IP アドレスへの、フラグメント禁止（DF）ビット付きの ICMP Echo（診断用の小さなパケット）。利用者が「実行」したとき。
利用者が入力した宛先のポートポートスキャン入力した宛先の、指定したポートへ TCP で接続します（開閉を調べるだけで、データは送りません）。初回に同意の画面で確認し、私設アドレス以外の宛先には実行のたびに確認します。同時接続数・時間・件数に上限があります。利用者が「実行」したとき（テストプランの手順として実行した場合を含む）。
利用者が入力した宛先（ホスト名またはグローバル IP アドレス）遠隔の Wake-on-LAN対象の MAC アドレスを含むマジックパケット（102 バイト）を、ユニキャストの UDP（ポート 9 または 7）で 1 回送ります。ホスト名は端末のリゾルバで解決します。ブロードキャスト・マルチキャストは送らず、届いたかどうかは確認しません。利用者が「起動」したとき。
同じ LAN 内の機器LAN 機器探索、ARP 画面の名前の問い合わせ、ローカルネットワークの許可の確認各機器の IP アドレスへ、mDNS の逆引き（UDP 5353）と NetBIOS の名前の問い合わせ（UDP 137）を、ユニキャストで送ります。LAN の外へは出ません。ARP 画面では、さらに各行の IP アドレスの逆引き（PTR）を、端末が使っている DNS サーバーに問い合わせます。「許可を求める」を押したときは、Bonjour の探索と、既定ゲートウェイ（Wi-Fi・有線で私設アドレスのときだけ）への TCP 接続を 1 回試します（応答の有無を見るだけで、中身は送りません）。LAN 機器探索や ARP 画面を使ったとき。
Google Public DNS、Quad9DoH／DoT の確認入力したドメイン名の DNS 問い合わせ。利用者が「実行」したとき。
NTP サーバー：ntp.nict.jp（NICT）、time.nist.gov（NIST）、ptbtime1.ptb.de（PTB）、time.cloudflare.com（Cloudflare）、time.google.com（Google）、time.aws.com（Amazon）、time.windows.com（Microsoft）、time.apple.com（Apple）、time.facebook.com（Meta）のうち選んだもの、および利用者が入力した NTP サーバーNTP（時刻のずれの確認）時刻の問い合わせ（端末の現在時刻を含む小さなパケット）。利用者が「実行」したとき。
IANA（data.iana.org、whois.iana.org）、およびそこで示されるレジストリ・レジストラ・地域インターネットレジストリの RDAP／WHOIS サーバーWHOIS／RDAP 検索入力したドメイン名または IP アドレスが、その登録情報を管理する RDAP サーバー（HTTPS）または WHOIS サーバー（TCP 43）に送られます。どのサーバーかは IANA の公開データで決まり、サーバーの事業者は入力内容と端末の IP アドレスを知り得ます。利用者が「実行」したとき。
Apple（captive.apple.com）、Google（connectivitycheck.gstatic.com）、Microsoft（www.msftconnecttest.com）、Firefox（detectportal.firefox.com）接続性の判定（キャプティブポータルの確認）暗号化されていない HTTP の GET のみ（通信のみ）。4 社へ並行して行い、端末の IP アドレスが届きます。接続性を確認したとき、またはクイック診断を実行したとき。
Google（AdMob、UMP）広告の表示（無料版）、同意の管理5 章のとおり。
iCloud（利用者本人のプライベートデータベース）Pro の同期（任意）履歴、ブックマーク、レポートの下書き、テストプラン、LAN 機器に付けた名前（設定は含みません）。4 章のとおり。同期を有効にしたとき。

本アプリは、これらの通信先に、広告を除き、端末の識別子や位置情報を送りません。WHOIS／RDAP では、結果を送ることもありません。IANA の公開データ（登録情報の問い合わせ先の一覧）は、再取得を減らすため、端末の中に最長 24 時間保存されます（個人情報を含みません）。

テストプランは、新しい通信先を増やしません。手順は、上の表の各機能と同じ宛先に同じ内容で通信し、利用者が入れた宛先に対して、利用者が「実行」したときだけ動きます。

3. 端末の中で扱う情報

  • 診断の結果の履歴、ブックマーク、しきい値などの設定、ピン留め、登録した端末の名前、LAN 機器に付けた名前（MAC アドレスまたは IP アドレスと名前。Pro）、遠隔 Wake-on-LAN の宛先（ホスト名・ポート・MAC アドレス）など。端末の中（アプリの保存領域）に保存されます。
  • テストプラン（名前、メモ、手順、合否の基準、対象のホスト名や IP アドレス。SNMP のコミュニティ名は保存しません）と、その実行結果（実行 1 回につき履歴に 1 件。手順ごとの合否、測った値、各ツールの結果）。ネットワーク情報の手順を含むときは、その結果として SSID とグローバル IP アドレスが履歴に入ります。LAN 探索・ポートスキャンの手順を含むときは、見つかった機器やポートも入ります。テストプランの PDF には、SSID とグローバル IP アドレスの範囲の基準について「一致／不一致」だけを書き、SSID やグローバル IP アドレスの値は載せません。書き出し・共有・印刷した PDF は、利用者が選んだ先に渡ります（アプリが送ることはありません）。
  • 経路表・ARP・VPN／プロキシの結果。利用者が「履歴に保存」を押したときだけ保存します（ARP の結果には MAC アドレスと機器名が入ります。グローバル IP アドレスは入りません）。
  • 接続中の Wi-Fi の名前（SSID）。ホーム画面での表示のために取得し、診断の結果に付けて履歴に保存することがあります（ウォークテストでは、回線が切り替わったことだけを記録し、SSID の名前は保存しません）。SSID の取得には、iOS の仕組み上、位置情報の許可（使用中のみ）が必要です。本アプリは位置情報を使いません。位置情報を記録も送信もしません。
  • SNMP のコミュニティ名。入力したものはアプリのメモリ上だけに置き、保存も送信（入力した宛先への SNMP 要求を除く）もしません。履歴、共有、CSV／JSON の書き出し、ブックマークにも含まれず、アプリを終了すると消えます。
  • ウィジェット。ウィジェットは通信しません。アプリが取得済みのグローバル IP アドレスや接続状態を、端末の中で共有して表示するだけです。ロック画面やホーム画面に IP アドレスなどが表示されると、端末を見る第三者にも見える可能性があります。ロック中は表示を伏せる設定にしています。ウィジェットは Pro の機能です。
  • ショートカット。Ping や DNS などの診断をショートカットから実行できます。結果は端末の中のショートカットに渡されるだけで、当方には届きません。実行した診断の通信は 2 章のとおりです。「テストプランを実行」で選べるように、プランの ID と名前だけを端末の中に写して持ちます（手順や基準は含みません）。
  • ローカルネットワークの許可。LAN の探索などを使うときだけ、用途を説明したうえで iOS が許可を求めます。同じ LAN 内の機器への通信（名前の問い合わせを含む。2 章）と、端末の ARP 表の参照に使います。ARP 表から読み取った MAC アドレスや機器名を、端末の外へ送ることはありません。
  • MAC アドレス。iOS は、自分の端末の MAC アドレスや周辺のアクセスポイントの情報をアプリに提供しないため、本アプリはそれらを取得しません。同じ LAN 内の他の機器については、iOS が提供する範囲で表示します。他の機器の MAC アドレスは、LAN の機器の一覧に表示するためだけに端末の中で読み、端末の外へは送りません（遠隔 Wake-on-LAN では、利用者が宛先として入力した MAC アドレスを、入力した宛先へ送ります）。
  • 購入の情報。Pro の購入は Apple が処理します。本アプリはクレジットカードなどの情報を扱いません。

4. iCloud での同期（Pro・任意）

Pro で同期を有効にした場合に限り、履歴（SSID を含む場合があります）、ブックマーク、レポートの下書き、テストプラン、LAN 機器に付けた名前を、利用者本人の iCloud のプライベートデータベースに保存し、同じ Apple ID の他の端末と同期します。しきい値などの設定やピン留めは同期せず、端末の中にだけ保存されます。同期はアプリ内の同意の画面で確認してから有効になり、既定では無効です。当方はこのデータを受け取らず、読むこともできません。iCloud での取り扱いは Apple の規約とプライバシーポリシーに従います。

5. 広告と同意

無料版では、画面の下部に Google AdMob（Google LLC）の広告を 1 つ表示します。Pro を購入すると広告は表示されません。購入済みと確認できた起動では、広告 SDK を初期化せず、広告のための通信もしません。

  • 広告の配信、成果の測定、不正の防止のため、広告 SDK は、広告用の識別子（IDFA）、端末の情報（機種、OS のバージョン、言語など）、IP アドレス（おおよその位置の推定に使われることがあります）、広告の表示や操作の状況などを Google に送ります。これらの情報は当方には届きません。
  • 起動時などに、Apple の App Tracking Transparency により、トラッキングの許可を求めることがあります。許可した場合に限り、広告 SDK は IDFA を使って広告をパーソナライズし、成果を測定します。許可しない場合も広告は表示されますが、IDFA は使われず、パーソナライズされません。いつでも、端末の「設定」＞「プライバシーとセキュリティ」＞「トラッキング」で変更できます。
  • 広告をパーソナライズするのは、App Store の国・地域が日本、米国、EEA、英国、スイスの利用者だけです。ほかの国・地域の利用者には、トラッキングの許可を求めず、常にパーソナライズしない広告を表示します（IDFA は使いません）。
  • 欧州経済領域（EEA）、英国、スイスの利用者には、広告を読み込む前に、Google の同意管理（UMP）の画面を表示します。米国の利用者には、州法に基づく選択のメッセージを表示します。選択は、アプリの設定の「プライバシー設定（広告）」（地域によって表示される項目）から見直せます。
  • Google による情報の取り扱いは、Google のプライバシーポリシーに従います。
  • 広告を許可しなくても、本アプリのすべての機能を使えます。

6. 子どものプライバシー

本アプリは、13 歳未満の子どもを対象としていません。当方は、13 歳未満の子どもから個人情報を意図的に収集しません。お子さまが情報を提供したと思われる場合は、12 章の連絡先へご連絡ください。

7. 保存期間と削除の方法

  • 履歴、ブックマーク、テストプラン、LAN 機器に付けた名前、設定：端末の中に、利用者が削除するまで保存されます。アプリ内の履歴・ブックマークの削除機能で削除できます。アプリを削除すると、端末の中のデータも削除されます。
  • iCloud の同期データ：同期を有効にしている間にアプリ内で履歴などを削除すると、その内容が iCloud 側にも反映されます。同期を無効にしても、すでに iCloud にあるデータは消えません。iCloud に残るデータを消すには、同期が有効なうちにアプリ内で削除するか、端末の「設定」＞ 自分の名前 ＞「iCloud」＞「ストレージを管理」から削除してください。
  • IANA の公開データの写し：最長 24 時間で更新され、アプリを削除すると消えます。
  • ポートスキャンの最初の同意：端末の中に保存され、アプリの設定から取り消せます。私設アドレス以外へのポートスキャンの確認と、SNMP のコミュニティ名は、その実行の間だけメモリに持ち、保存も送信もしません。
  • 速度測定の同意：アプリの設定の「速度測定の同意」で内容を確認し、取り消せます。取り消すと、次の速度測定の前にもう一度確認します。
  • 第三者に届いた情報（速度測定で Cloudflare に届いた通信、広告 SDK が Google に送った情報など）：当方は削除できません。各事業者のポリシーをご確認ください。

8. 第三者への提供

当方は、法令に基づく場合を除き、利用者の情報を第三者に提供しません。ただし、2 章と 5 章のとおり、利用者が実行した診断や広告のために、端末から第三者のサービスへ情報が送られます。

9. 外部ライブラリとサービス

本アプリは、広告のために Google Mobile Ads SDK と Google User Messaging Platform を使用します。アプリが使用する第三者のデータやサービスは、アプリの設定の「ライセンスと出典」にも記載しています。
