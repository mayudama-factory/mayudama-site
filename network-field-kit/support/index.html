よくある質問

Wi-Fi の名前（SSID）が表示されません。
iOS は、SSID の取得に位置情報の許可（使用中のみ）を求めます。端末の「設定」＞「プライバシーとセキュリティ」＞「位置情報サービス」で Network Field Kit を「このアプリの使用中のみ許可」にしてください。本アプリは位置情報を記録も送信もしません。モバイル回線に接続中、VPN の利用中、Wi-Fi に接続していないときは、表示されません。

「ローカルネットワーク」の許可を求められます。
LAN の探索など、同じネットワーク内の機器に通信する機能を開いたときだけ求めます。許可しなくても、他の機能は使えます。あとから変えるときは、「設定」＞「プライバシーとセキュリティ」＞「ローカルネットワーク」で変更できます。

MAC アドレスが表示されない（取得できない）のはなぜですか。
iOS は、自分の端末の MAC アドレスや、周辺のアクセスポイントの情報をアプリに提供しません。取得できない情報を、取得できるかのように表示することはしません。同じ LAN 内の他の機器の MAC アドレスは、iOS が提供する範囲で表示します。

速度測定で IP アドレスが公開されると聞きました。
速度測定には M-Lab（Measurement Lab）を使います。M-Lab は、測定結果を、測定した端末の IP アドレスを含めて、公開データとして公開します。このため、初回の測定の前に同意の画面を表示し、「同意して開始」を押したときだけ測定を始めます。M-Lab が使えないとき、または M-Lab の利用ルールに合わせた回数の上限（24 時間に 20 回）に達したときは Cloudflare で測定することがあり、その場合も端末の IP アドレスと測定の通信が Cloudflare に届きます。同意は、アプリの設定の「速度測定の同意」で確認・取り消しできます。モバイル回線では通信量が多くなります。詳しくはプライバシーポリシーをご覧ください。

広告について。
無料版では、画面の下部にバナー広告を 1 つ表示します。Pro を購入すると表示されなくなります。トラッキングの許可（ATT）や同意の画面（UMP）で許可しなくても、すべての機能を使えます。許可しない場合、広告はパーソナライズされません。

Pro の購入を復元したい。
アプリの設定の「Pro の内容を見る・購入・復元」を開き、「購入を復元」を押してください。購入したときと同じ Apple ID で使えます。

iCloud での同期について。
同期は Pro の機能で、既定では無効です。有効にすると、履歴（SSID を含む場合があります）、ブックマーク、レポートの下書きが、ご自身の iCloud に保存され（しきい値などの設定は同期しません）、同じ Apple ID の他の端末と共有されます。使うには、端末が iCloud にサインインしていて、本アプリの iCloud が許可されている必要があります。同期されないときは、「設定」＞ 自分の名前 ＞「iCloud」を確かめてください。

ウィジェットが更新されない／IP アドレスが表示されません。
ウィジェットは通信しません。アプリが取得した直近のグローバル IP アドレスや接続状態を表示するので、先にアプリを開いてホーム画面で取得してください。ロック画面では、端末がロックされている間は表示を伏せます。

ショートカットから使えますか。
Ping や DNS などの診断を、ショートカット App のアクションとして実行できます。画面は開かず、結果が文字として返ります。ショートカットの後続のアクションで使えます。

既知の制約

  • iOS の仕様により、自分の端末の MAC アドレスと、周辺のアクセスポイントの情報は取得できません。
  • iOS のバージョンによっては、同じ LAN 内の他の機器の MAC アドレスを取得できないことがあります。
  • ネットワーク機器の中には、Ping などの応答を返さない設定のものがあります。応答がないことが、障害を意味するとは限りません。
  • 速度測定の結果は、測定先、時間帯、回線の混雑、端末の状態によって変わります。目安としてご利用ください。
  • SNMP は v2c のみに対応しています。コミュニティ名は平文で送られます。
  • VPN の利用中や、ネットワークの設定によっては、結果が通常と異なることがあります。
